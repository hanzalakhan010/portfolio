# Hanzala Khan - Portfolio

Welcome to my personal portfolio website. This project showcases my work as a **full-stack & backend engineer** and founder of **H++ Solutions**, an EdTech venture.

## Live Demo
https://hanzalakhan010.github.io/portfolio/

## Tech Stack
- **Frontend**: HTML5, Tailwind CSS
- **Icons**: FontAwesome
- **Fonts**: Inter, JetBrains Mono (Google Fonts)
- **Deployment**: GitHub Pages

## Project Structure
- `index.html`: Main landing page with About, Experience, Education, and Certifications sections.
- `projects.html`: A grid layout showcasing my various projects (Private & Public).
- `image.png`: Profile image.
- `resume.pdf`: Downloadable resume, linked from the nav.

## Features
- **Modern UI**: Dark-themed, developer-focused design using Tailwind CSS.
- **Responsive Usage**: Fully responsive layout for mobile, tablet, and desktop.
- **Interactive Elements**: Hover effects on project cards and profile image.

## Setup
This is a static website. You can simply open `index.html` in any modern web browser.

To make changes to styles, you can edit the Tailwind classes directly in the HTML files. No build step is required as it uses the Tailwind CDN.

```bash
# Clone the repository
git clone https://github.com/hanzalakhan010/portfolio.git

# Open index.html
open index.html
```
